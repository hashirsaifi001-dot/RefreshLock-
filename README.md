# RefreshLock-
Minimalist root app for Android that locks your display to 120 Hz with one tap. A glass-style circle toggles the lock on or off. If the phone gets warm it drops to 90 Hz, then 60 Hz when hot, and steps back up as it cools. Shows live SoC and battery temperature. Built for a rooted Realme 12x on Android 16. Use at your own risk.
